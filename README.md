# HwanHon 환혼(구 HideAndSeek) Game
## 개요
| 영상 | 설명 |
|------|------|
| [![Video Label](http://img.youtube.com/vi/zMfVIc-UB20/0.jpg)](https://youtu.be/zMfVIc-UB20) | 트레일러 영상입니다. |
| [![Video Label](http://img.youtube.com/vi/mdFIM5wtNtc/0.jpg)](https://youtu.be/mdFIM5wtNtc) | 포트폴리오 영상입니다. |

* 환혼은 Shadow Corridor 시리즈와 Monstrum에 영감을 받아 제작한 1인칭 생존 호러 게임입니다.
* Shadow Corridor 시리즈처럼 1인 개발을 목표로 한 게임입니다.
* 챕터 2에서는 맵과 아이템이 무작위로 배치됩니다.

## 사용 기술
* 엔진: Unreal Engine 5 5.1.1
* 에디터: Microsoft Visual Studio 2022
* 모델링: Blender
